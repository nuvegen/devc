devc

Entwicklungs-Container
für KI-Agenten

Ein Klick, und Claude Code hat eine eigene, abgeschlossene Arbeitsumgebung. Bedient wird alles im Browser.

Container in LXD · Web-Oberfläche und Kommandozeile · Addons

1
Die Idee

Jedes Projekt bekommt seinen eigenen Container

  • Der Agent arbeitet im Container, nicht auf deinem Rechner. Was dort passiert, bleibt dort.
  • Jeder Container ist jederzeit neu aufbaubar: aus einer Vorlage, Addons und einer Textdatei.
  • Code und Home liegen auf eigenen Volumes und bleiben dabei erhalten.
2
Anlegen

Ein neuer Container mit einem Klick

  • Vorlage wählen, Namen eintragen, fertig.
  • Die Vorlage bringt alles mit: Sprache, Claude Code, Git, Werkzeuge.
  • Eigene Vorlagen entstehen aus einem Container, der dir gefällt.
3
Überblick

Alles zu einem Container auf einer Seite

  • Terminal, Dateien, Konfiguration, Secrets, Snapshots und Backups.
  • Addons legen eigene Kacheln dazu, hier »Claude« und »Git«.
  • Starten, Stoppen und Neustarten ohne Umweg.
4
Claude Code

Mit Claude Code im Browser arbeiten

  • Schreiben wie in einem Chat, ohne ein Terminal zu öffnen.
  • Du siehst, was Claude tut, und gibst Befehle und Änderungen frei.
  • Die Unterhaltung läuft weiter, wenn du den Browser schließt.
5
Terminal

Ein richtiges Terminal, direkt im Browser

  • Mehrere Sitzungen als Tabs, als Nutzer dev oder root.
  • Sitzungen bleiben offen, auch nach dem Neuladen der Seite.
  • Wer lieber die Kommandozeile nimmt: devc shell <name>.
6
Git

Commit, Push und Pull ohne Kommandozeile

  • Findet die Repositories im Container von selbst.
  • Zeigt, was sich geändert hat, auch das, was Claude geändert hat.
  • Ein Commit lässt sich mit einem Klick rückgängig machen.
7
Addons

Werkzeuge nach Bedarf dazunehmen

  • Ein Addon bringt ein Werkzeug in den Container, mit Einstellungen und Knöpfen.
  • httpserver zeigt einen Ordner im Browser. webproxy macht eigene Dienste erreichbar.
  • Eigene Addons sind ein Ordner mit ein paar Textdateien.
8
Unter der Haube

Offen und einfach gebaut

Eine Dateidevc ist ein Python-Programm in einer Datei. Es braucht nur die Standardbibliothek.
Offene FormateKonfiguration, Vorlagen und Addons sind Textdateien (TOML, Markdown, Shell).
Browser und KommandozeileBeide können dasselbe. Alles lässt sich auch in Skripten nutzen.
AbgeschottetJedes Projekt läuft in einem eigenen Container in LXD. Secrets liegen in einem eigenen Speicher.
GesichertSnapshots und Backups je Container, dazu Versionierung mit Git: Commit, Push und Pull in der Oberfläche.
ErweiterbarAddons bringen eigene Kacheln mit: Ansichten, Chats, bedienbare Seiten.
9
Loslegen

In wenigen Minuten startklar

  • Eine frische Ubuntu-VM richtet sich mit einer fertigen Datei selbst ein.
  • Danach gibt es devc im Browser und auf der Kommandozeile.
  • Anleitung: README.md und docs/HILFE.md im Repository.
# Vorlagen ansehen
devc template list

# Container anlegen
devc create py-tools --template pydev

# Shell im Container
devc shell py-tools
