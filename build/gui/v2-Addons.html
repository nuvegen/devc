Hochladen: ein Archiv (.tar.gz oder .zip) mit genau einem Addon-Ordner. devc prüft addon.toml, README.md und AI.md, bevor das Addon verfügbar wird. Gleiche id ersetzt das eigene Addon; Container übernehmen die neue Version erst über Konfiguration › Anwenden. Mitgelieferte Addons lassen sich nicht löschen, nur durch ein eigenes mit gleicher id überschreiben. Löschen geht nur, solange kein Container das Addon nutzt.
